## How to Run

```bash
# Populate all sauce chains (requires DB access)
python manage.py import_live_sauce_chains

# Single chain
python manage.py import_live_sauce_chains --chain GFF127R

# Dry run (no DB writes)
python manage.py import_live_sauce_chains --dry-run
```
